# 2단계 작업 나누기 (헤드 + 도우미 4)

업데이트 1~8을 네 갈래로 나눈다. 헤드 스레드가 전체를 조율하고 PR을 검토·합치고 TestFlight를 올린다.

## 공통 규칙

- **브랜치**: 각자 `t/<이름>` 브랜치(아래 표)에서 일하고, 기능 단위로 작은 PR을 `main`에 연다. `main`에 직접 push하지 않는다.
- **PR 전에**: `git fetch origin main && git rebase origin/main`, 그리고 `npm test`와 `npm run build`가 통과해야 한다.
- **합치기**: 헤드가 검토하고 합친다. 도우미는 자기 PR을 합치지 않는다.
- **내 파일만 크게**: 아래 표의 "소유 파일"은 마음껏 바꾼다. 공용 파일(`src/game.js`, `src/npc.js`, `src/data.js`, `src/save.js`, `src/hooks.js`)은 **덧붙이기만** 하고, 고칠 땐 작은 커밋으로 따로 한다. 다른 갈래 소유 파일은 손대지 않는다. 꼭 필요하면 헤드에게 말한다.
- **끼어드는 방법**: `game.js`의 한 달 흐름을 고치는 대신 `src/hooks.js`의 `HOOKS`에 함수를 등록한다. 새 행동은 `ACTIONS.push(...)`, 새 사건은 `EVENTS.push(...)`를 자기 모듈에서 하고, `src/content.js`에 import 한 줄만 추가한다.
- **저장 호환**: 상태에 새 필드를 더하면 `HOOKS.newGame`과 `HOOKS.migrate`에서 기본값을 채운다. 예전 저장이 깨지면 안 된다.
- **톤**: 진지하고 어른스러운 판타지 (오버로드·무직전생 쪽). 동화풍·유치한 글 금지. 세계 설정 문서를 따른다. 모든 글은 한국어.
- **보고**: PR을 열었을 때, 막혔을 때, 다른 갈래와 겹칠 때 헤드 스레드에 메시지를 보낸다.

## 갈래

| 갈래 | 업데이트 | 브랜치 | 소유 파일 |
|---|---|---|---|
| A 화면과 그림 | 1 | `t/ui` | `style.css`, `index.html`, `src/ui.js`(→ `src/ui/` 로 나눠도 됨), `src/art/` |
| B 관계와 이야기 | 2, 3 | `t/relations` | `src/relations.js`, `src/narrative/`, `src/actions.js`의 결과 글 |
| C 사건과 세계 흐름 | 4, 8 | `t/events` | `src/events.js`(→ `src/events/`), `src/world.js` |
| D 성인 이후 삶·모험·대 잇기 | 5, 6, 7 | `t/life` | `src/jobs.js`, `src/places.js`, `src/factions.js`, `src/adventure/`, `src/heir.js` |

### A 화면과 그림 (업데이트 1)
- 행동 고르기를 드롭다운 대신 터치 카드로. 폰 화면을 먼저 생각한다.
- 계절·시간에 따라 바뀌는 마을 풍경 (캔버스로 절차 생성).
- 인물 초상: 얼굴 부위를 조합해 자동으로 그리는 방식(SVG/캔버스). 나이·성별·집안에 따라 달라지고, 같은 사람은 늘 같은 얼굴.
- 양피지 대륙 지도 화면 (기존 지도 Artifact https://claude.ai/artifact/XeJrYNN8K4EgstHB4VXK9B 의 그리기 코드를 가져와 씀). D가 만드는 장소·이동과 연결.
- 사건 창, 인물 수첩도 다시 디자인. 게임 규칙은 바꾸지 않는다.

### B 관계와 이야기 (업데이트 2, 3)
- 행동 결과를 숫자 나열 대신 짧은 장면 글로. 상황·나이·성격·관계에 따라 갈라진다. 숫자는 작게 덧붙인다.
- 관계 종류: 친구, 라이벌, 첫사랑, 연인, 배우자, 원수. NPC가 플레이어와 있었던 일을 기억한다(`person.memories`).
- 대화 선택지 (찾아가기 행동을 장면으로), 고백·청혼·결혼, 플레이어의 자식 낳기.
- NPC끼리의 관계도 조금 (소식에 반영).

### C 사건과 세계 흐름 (업데이트 4, 8)
- 사건 100개 이상. 나이대·집안·계절·능력·관계에 따라. 몇 달에 걸쳐 이어지는 이야기 줄기(사건 체인) 포함.
- 세계 흐름: 레오니아 왕국 정세, 영주, 전쟁, 마물 피해, 물가, 기술 시대 변화. `world.js`로 분리하고 소식에 나오게.
- 설정 문서의 인물·세력·역사를 사건에 녹인다.

### D 성인 이후 삶·모험·대 잇기 (업데이트 5, 6, 7)
- 15살 이후: 견습 → 직업, 수입, 집 구하기. 직업별 행동.
- 장소: 에른 마을 → 하르펜(소도시) → 영지 → 왕도. 이사와 여행(이동에 달이 걸림). 장소마다 다른 행동·사람.
- 소속: 기사단, 모험가 길드(F~S 등급), 상단, 성광교. 들어가기·승급.
- 모험: 작은 미궁, 전투는 압승·교전부터 (전투 아이디어 모음 문서 참고). 부상·흉터와 연결.
- 대 잇기: 플레이어가 죽으면 자식 중 한 명으로 이어 하기 (재산·인맥 상속).
